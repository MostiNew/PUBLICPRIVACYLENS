# PrivacyLens — Real-Time Face Blurring for Smart Glasses

**Privacy for everyone.** Scan a QR code, and all faces are blurred in real-time.

## Features
- 🔒 Real-time face blurring
- 📸 QR code zone detection
- 👤 Public & private zone policies
- 🚫 No recording — just live privacy
- 📡 No network required (offline-ready)

## How to Use
1. Open the app on your smart glasses or phone
2. Tap to scan a QR code at the zone entrance
3. All faces are blurred in real-time
